# ADR-007: Feature 与模型版本独立

状态：接受。范围：本轮只实现 Feature 版本；2026-10-01。

当前唯一 Feature 实现为 p4-features-v1，质量规则 availability-v1 随 Feature 版本固定。任何输出语义、缺失策略、评分规则、阈值或来源选择变化必须新增 feature_version；保留旧构建器/发布工件用于重建，不把旧标签指向新算法。调用者不能用任意字符串给同一算法伪造版本。

未来 model_version 必须绑定代码版本、训练数据/时间范围、超参数、随机种子、依赖及模型工件摘要，训练样本引用不可变 Feature id，时间拆分避免标签和赛后数据泄漏。相同输入及工件可重复执行，版本间可独立回测。

本轮没有模型，不给 Feature 填虚构 model_version，不建立空模型注册表，不提前实现训练、推理或回测产品。跨平台依赖锁、模型注册及版本工件归档列为后续工作。
