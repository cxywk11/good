# ADR-008: 推荐能力必须独立验收

状态：接受，仅政策，不实现推荐 Gate 服务；2026-10-01。

可生成 Feature 不代表数据源已通过真实验收，也不代表可以发布推荐。data_quality_score 是固定规则的输入可用性分数，不是胜率、模型置信度、收益率或投注许可；Mock 的 100 分只能说明合成证据齐备。

未来进入推荐阶段至少需要真实体彩主池/海外来源验收、映射核验、cutoff 泄漏回归、可重现模型工件、按时间拆分的回测/校准与缺失处理方案，具体通过标准在另行授权阶段定义，不凭空指定收益门槛。

本轮保持 CORE/WATCH/PASS、EV 推荐、串关、LLM 推荐、自动投注、最终预测模型关闭，不增加这些接口或空壳实现。原 Phase 1 阻塞 Gate 不因 Feature 测试通过而自动关闭。
