# Entity Resolution

主队 35、客队 35、开球时间 20、联赛 10。只有已验证的 provider ID → UUID 贡献球队或联赛分。
时间差 ≤5 分钟得 20；≤30 得 15；≤120 得 5；其余 0，候选窗口 ±4 小时。
自动确认阈值、审核阈值、候选最小分差在 .env 配置。默认 95 / 80 / 5。
低于 80 为 UNMATCHED；95 以上仍需主客身份齐全、无歧义且无同源目标冲突才自动确认。
名称标准化为 Unicode NFKC + casefold + 空白归一，保留 Women、U21 等信息，仅供候选展示。
更名不变更身份。球队 ID 或开球时间变化令已确认映射进入 REVIEW，并写 AuditLog。
人工确认/拒绝/重绑必须带理由、操作者、请求 ID 和乐观版本。已有赔率保留原 mapping_version。
